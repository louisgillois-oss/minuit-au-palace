# Minuit au Palace

Jeu de rôles cachés au style art déco, pour 6 à 18 joueurs, animé par le maître du jeu sur un seul téléphone.

- `app.html` : source de l'application.
- `docs/` : version installable (PWA), servie par GitHub Pages. Elle fonctionne hors ligne une fois chargée.
- `./build.sh` : régénère `docs/` après une modification de `app.html`.

## Installer sur le téléphone

Ouvrir la page GitHub Pages dans le navigateur, puis :
- **Android (Chrome)** : menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- **iPhone (Safari)** : bouton Partager → « Sur l'écran d'accueil ».
